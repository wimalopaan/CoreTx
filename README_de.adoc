= CoreTX

link:README.adoc[English]

WARNING: Experimentelle Firmware: Vor Versuchen Motoren abklemmen/Propeller entfernen.
Originalfirmware und externes EEPROM getrennt sichern.
Neutrale Kanalausgabe ist kein garantierter Motor-Aus-Failsafe.

Experimentelle Firmware für *Flysky FS-i6X und FS-i6S* mit STM32F072,
128 KiB Flash und 16 KiB RAM. Aktuelle Firmwareversion im Quellcode: *4*
(`coretx/version.hpp`).

== Ziele

* ISO C++26, einen Header-only-Kern samt UI und Template-Metaprogrammierung
  für Konfiguration und Prüfungen zur Compilezeit verwenden.
* Die ganzzahlige Kanalberechnung von EdgeTX `Inputs -> Mixer -> Outputs`
  einschließlich Rundung und Begrenzung erhalten.
* Deterministische, kooperative Main-Loop ohne RTOS, dynamische Speicherverwaltung,
  Gleitkomma, Exceptions oder RTTI.
* CRC-geschützte Binärdaten im externen I2C-EEPROM des Senders statt YAML und
  SD-Karte. Modell- und Mischerkapazitäten bleiben bewusst begrenzt.
* Kompakte, vertraute 128x64-Oberfläche: Tasten beim i6X, Touch beim i6S.
* Internes A7105/AFHDS 2A oder externes UART-CRSF-Modul; andere Protokolle und
  heli-spezifische Funktionen entfallen.

== Releases, Bauen und Flashen

Senderspezifische Binärdateien stehen unter
https://github.com/wimalopaan/CoreTx/releases[GitHub Releases].
Falls für einen Sender kein Abbild angeboten wird, lokal bauen; niemals eine
i6X-Firmware auf einen i6S übertragen.

Beide Menüsprachen mit CMake >= 3.30, Ninja und einer ARM-GCC-Toolchain mit
C++26-Unterstützung bauen:

[source,shell]
----
cmake --preset i6x
cmake --build --preset i6x
cmake --preset i6s
cmake --build --preset i6s
----

Die passende `.bin` als *lokale Firmwaredatei* mit dem
https://ferroxrc.com/flasher[Ferrox Web Flasher] in einem WebUSB-fähigen Browser
übertragen. Nicht stattdessen einen Ferrox-Firmwaredownload auswählen.
Siehe link:BUILDING_de.adoc#first-flash[Hardware-Vorbereitung zum Erstflash].
Voraussetzungen, Sicherungen sowie `dfu-util` und `rdfu`:
link:BUILDING_de.adoc[Bauen, alle CMake-Optionen und Flashen].
Für spätere Updates beim Einschalten beide horizontalen Trimmungen nach innen
(i6X) beziehungsweise beide Rücktasten SE/SF (i6S) halten: ROM-DFU ohne Öffnen.

== Erweiterungen

* *Externes CRSF:* bidirektionale UART für Kanalausgabe, Telemetrie und
  Modulkonfiguration. Es ist immer nur ein HF-Pfad aktiv.
* *MultiSwitch:* CRSF-Dashboards und SET4-Befehle für kompatible Empfänger/Module.
* *Zusätzliche Eingänge:* einzeln abschaltbare Potis und analoge Stufenschalter;
  zusätzliche Digitalschalter lassen sich ebenfalls abschalten und, soweit
  unterstützt, zu Dreistufenschaltern kombinieren.
  Beim i6S gibt es zusätzlich eine nur im Setup aktive Tasten-/Slider-Navigation.

Verdrahtung, Pinbelegung, Versorgung und Grenzen sind getrennt beschrieben:
link:PERIPHERALS_de.adoc#i6x[FS-i6X] und link:PERIPHERALS_de.adoc#i6s[FS-i6S].
Siehe auch link:COMPATIBILITY.adoc[EdgeTX-Kompatibilität und bewusste Einschränkungen (EN)].
