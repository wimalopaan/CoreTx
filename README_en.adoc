= CoreTX

link:README_de.adoc[Deutsch] | *English* | link:README.adoc[Language selector]

Experimental C++26 transmitter firmware for Flysky FS-i6X and FS-i6S with
STM32F072xB. Bare-metal, without an RTOS, heap allocation or floating point:
`Inputs -> Mixer -> Outputs` uses integer arithmetic.
Supports model management, calibration, logical switches, internal
A7105/AFHDS 2A and external CRSF. Not a complete EdgeTX replacement.

Current firmware version: *3*. Firmware versions are integers
and independent of the storage format.

== Build and try

Run from the project directory. Requires CMake >= 3.30, Ninja, Python 3
and a C++26 compiler; firmware needs a suitable ARM GCC toolchain.
The first configuration downloads the required CMSIS sources.

[source,sh]
----
cmake --preset i6x
cmake --build --preset i6x
cmake --preset i6s
cmake --build --preset i6s
----

Each board build produces both languages:

* i6X: `build-i6x/coretx-i6x-de.bin` and `build-i6x/coretx-i6x-en.bin`.
* i6S: `build-i6s/coretx-i6s-de.bin` and `build-i6s/coretx-i6s-en.bin`.

GitHub Actions builds i6X on pushes, pull requests and manual runs.
Under https://github.com/wimalopaan/CoreTx/actions/workflows/i6x.yml[Actions],
the `coretx-i6x-de-en` artifact contains the German and English `.bin` and `.hex` files.
Version tags such as `v3` also publish these files under
https://github.com/wimalopaan/CoreTx/releases[Releases].

Matching `.elf` and `.hex` files are in the same directory.
The image starts at `0x08000000`; these commands do *not* flash it.
Alternatively: https://ferroxrc.com/flasher[Ferrox-RC Web Flasher] (WebUSB, Chrome/Edge).
Select the matching transmitter platform and your own CoreTX `.bin`,
not the offered Ferrox releases.
Back up the original firmware and EEPROM before programming.

Desktop simulator (POSIX system with SDL3):

[source,sh]
----
cmake --preset build -DTRANSLATION=EN
cmake --build --preset build
./build/coretx_simulator
----

`TRANSLATION=EN|DE` selects the native language; firmware builds include both.
`CORETX_A7105`, `CORETX_CRSF`, `CORETX_MULTISWITCH` and
`CORETX_EXTENDED_INPUTS` default to
`ON`; disable one with e.g. `cmake --preset i6x -DCORETX_CRSF=OFF`.
Additional analog/digital inputs must also be enabled on the transmitter
and initially remain off there.

`CORETX_SECURE_UI` defaults to `OFF`: UI changes are allowed with RF ON.
Use `cmake --preset i6x -DCORETX_SECURE_UI=ON` to require RF OFF for
model management, calibration, stick mode, input assignments, RF format/baud rate
and switching trim modes. Storage and device checks remain enabled.

== Everyday use

Menu paths below use the English labels.
On i6X, hold OK to open the main menu; UP/DOWN selects or changes,
short OK opens/confirms, CANCEL discards/goes back.
On i6S, hold a stationary touch to open the menu;
vertical swipes select/change, right confirms, left cancels.
Simulator: Tab changes pages, arrow keys navigate, Enter confirms,
Esc cancels, Q quits; mouse/touch also works.

* `Models`: select, create, copy, rename or delete a model.
* `Model setup`: configure Inputs, Mixer, Outputs, logical switches and RF.
* `Radio setup`: stick mode, calibration and input assignments.
* Dashboard: Overview/System-Info; i6X UP/DOWN changes pages.

Eight models reside in external EEPROM. New models and model changes
leave RF off; explicitly enable output under `Model setup -> RF setup`.
With `CORETX_SECURE_UI=ON`, model management, calibration and input changes require RF OFF.
Wait for saving to finish before powering down.
Models and portable state files use storage format 6 only.
Recreate old models and calibration data; back up your data before updates/downgrades.

Under `Radio setup -> Input setup`, enable only controls actually wired.
To calibrate, first center the sticks and Pot-D controls, then move sticks
and all enabled Pot/Pot-D controls through their full ranges.
Calibration shows six rows per page; UP/DOWN changes pages.
Calibration and input assignments apply transmitter-wide.

== Trims

`Model setup -> Trims`: each i6X rocker T1–T4 acts either as a trim or a
momentary switch; use its position to select either direction independently.
Trimming and the momentary switch function also work with RF ON.
Only with `CORETX_SECURE_UI=ON` does switching between trim and momentary switch modes require RF OFF.
Trim values are per model, follow stick mode and range from −127 to +127.
The Input `Trim` field selects AUTO, OFF or freely assigned AIL/ELE/THR/RUD;
the mixer enables or disables carrying the associated trim.
Holding repeats; values are saved 500 ms after the last change.
On i6S, set the values in the menu; there are no virtual trim buttons.

== MultiSwitch

Requires `CORETX_MULTISWITCH=ON` and `CORETX_CRSF=ON`; disable with
`cmake --preset i6x -DCORETX_MULTISWITCH=OFF`. Stored settings are retained.
`Model setup -> MultiSwitch` configures up to four additional dashboard pages:
each has `OFF` or address 0–255, eight labels of six characters each
and Switch/Momentary types. Each function has output 1–8, its own/inherited address
and an optional physical/logical switch including its active position in one field
(e.g. `SA^`).
The overview shows `Output@Address`; duplicate active targets are rejected.
Assigned switches work offscreen; their tiles are display-only.
The active switch position appears below the tile label.
Page OFF disables all functions, including own addresses. All pages initially default to OFF.
Momentary buttons have a double frame; edit each function's label under `Text`.
Copy retains the configuration; live ON states are not saved.
Requires a valid, calibrated model and active external CRSF output;
MultiSwitch consumes no RC channels.

* i6X: short OK enters tile selection; UP/DOWN selects, OK toggles a switch
  or holds a momentary function. CANCEL leaves selection. Held OK opens the
  main menu *only outside* tile selection.
* i6S: tap a tile to toggle; a momentary tile stays ON only while touched.
  Swipe to change pages, tap the header for the next page;
  hold the footer to open the menu. Losing touch, changing pages or
  opening a menu releases a held momentary function.

== CRSF

First select external CRSF and the appropriate baudrate in `Model setup -> RF setup`,
then open `Radio setup -> CRSF configuration` for devices and parameters.
With `CORETX_CRSF=ON`, enable a page under `Model setup -> CRSF dashboard`,
independently of the MultiSwitch option.
OK starts interaction; long CANCEL (i6S: hold outside editing) restores
page navigation. Device pings run only while the device list is visible;
re-entry reloads the current folder's parameters.
The configuration menu does not enable RF implicitly.
UP/DOWN selects/changes, OK opens/confirms, BACK discards/goes back;
hold BACK to leave configuration. Check device compatibility on the bench.

== Safety and hardware

* Power off and disconnect the supply before any wiring.
* i6S J15 PB6/PB7 share the CRSF UART: extra switches and external CRSF
  are mutually exclusive. Disconnect/isolate soldered switches before CRSF use;
  disabling a menu option does not disconnect the wiring.
* i6S J4 PA13/PA14 takes over SWD pins; enabled extra inputs prevent SWD use.
* Do not treat hardware modifications or new features as validated on a real
  transmitter. Check the board revision and pin assignments before modifications.
* Missing/stale control values center channels at 1500 µs,
  *including throttle*: this is not a safe motor-off failsafe.
* Bench-test with motors/propellers disconnected. A successful build
  establishes neither flight safety nor permission to transmit.
